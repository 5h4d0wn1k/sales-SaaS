# Sales SaaS Launch Scope

Use this skill when changing public pages, pricing, onboarding, dashboard claims, or product copy in this repository.

## Launch principle

Do not expose or over-claim features that are not yet trustworthy for public beta.

## Current launch-safe focus

- landing page
- pricing
- get-started onboarding
- billing
- dashboard visibility
- lead and campaign foundations

## Guardrails

- If a capability is not truly implemented, hide it, gate it, or soften the claim.
- Prefer trustworthy, narrow workflows over broad “AI can do everything” messaging.
- Keep public copy aligned with current provider integration and automation reality.
- For user-facing changes, check:
  - onboarding flow
  - pricing path
  - dashboard rendering
  - billing entry and portal experience
